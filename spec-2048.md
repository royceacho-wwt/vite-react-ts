# Spec: 2048 Game

## Goal
Add a self-contained 2048 game page to the app. A player slides tiles on a 4×4 grid using
arrow keys, merging equal-value tiles to build toward the 2048 tile. The game ends in a win
when a 2048 tile is created, or in a loss when no legal moves remain.

---

## In Scope

### Navigation
- A "🎲 2048" entry appears in the NavBar and navigates to `/2048`
- The link receives the `navbar-link--active` class and `aria-current="page"` when the
  current path is `/2048`

### Board Setup
- The board is a 4×4 grid (16 cells), initially empty except for two randomly spawned tiles
- Each spawned tile has value 2 (90% probability) or 4 (10% probability)
- A "New Game" button resets the board to this initial state at any time

### Movement & Merging
- The player moves all tiles in a direction (Up / Down / Left / Right) using the
  corresponding arrow key
- **Slide rule**: in the chosen direction, all tiles in each row or column slide as far as
  possible, filling empty cells
- **Merge rule**: when two tiles of equal value collide while sliding, they merge into one
  tile whose value is their sum. Each tile may participate in **at most one merge per move**
- Merges are resolved before any remaining slide; tiles produced by a merge do not merge
  again in the same move
- After every move that changes the board, one new tile (2 or 4, same probabilities) spawns
  in a randomly chosen empty cell
- If a move does not change the board state, no tile spawns and the move is silently ignored

### Concrete merge examples (Left direction)
These examples must all produce the stated output; deviations are bugs:

| Input row        | Output row       | Notes |
|------------------|------------------|-------|
| `[2, 0, 0, 2]`   | `[4, 0, 0, 0]`   | Two 2s merge |
| `[2, 2, 0, 0]`   | `[4, 0, 0, 0]`   | Adjacent equal tiles merge |
| `[2, 2, 2, 2]`   | `[4, 4, 0, 0]`   | Two independent merges; each tile merges once |
| `[2, 2, 4, 0]`   | `[4, 4, 0, 0]`   | First pair merges to 4; existing 4 does not merge with result |
| `[2, 4, 2, 4]`   | `[2, 4, 2, 4]`   | No equal adjacent tiles; nothing merges |
| `[0, 0, 2, 2]`   | `[4, 0, 0, 0]`   | Slide then merge |

### Score
- A running score is displayed, starting at 0 each game
- Score increases by the value of each newly merged tile (e.g. merging two 4s adds 8)
- Multiple merges in a single move each contribute to the score
- Score resets to 0 on "New Game"
- Score is not persisted across sessions

### Win Condition
- The game is won the moment any tile reaches value 2048
- On win: the board freezes (no further input accepted), a win overlay/message
  ("You win! 🏆") is displayed, and a "New Game" button is shown
- There is no "keep playing" option; the game stops at 2048

### Loss Condition
- Loss is detected **after** the new tile spawns following a move
- The game is lost when: the board is full (no empty cells) **and** no two adjacent tiles
  (horizontally or vertically) share the same value
- On loss: the board freezes, a loss message ("Game over! 😢") is displayed, and a
  "New Game" button is shown

**Concrete full-but-not-lost example**: if after spawning the board is full but contains
at least one pair of adjacent equal values (e.g. two adjacent 4s), the game is NOT lost —
the next move can still merge that pair.

### Theming
- The page integrates with the existing `useDarkMode` / CSS variable system
- The empty-cell colour (`--color-tile-empty`) is defined in the page's CSS using the
  existing dark/light theme variables
- All other page chrome (background, heading, score label) uses existing CSS variables

---

## Out of Scope (Deferred)
- Touch / swipe input
- Best score (session or persisted)
- "Keep playing" after reaching 2048
- Animations / transitions on tile slide or merge
- Undo button
- Any grid size other than 4×4

---

## Prior Decisions
- Tile spawn probabilities: 90% chance of value 2, 10% chance of value 4
- Win is a hard stop at 2048; no continuation

## Acceptance Criteria

### Navigation
- [ ] Navigating to `/2048` renders the 2048 game page
- [ ] The NavBar "🎲 2048" link is present and navigates to `/2048`
- [ ] The NavBar link has `aria-current="page"` only when the current path is `/2048`

### Board Initialisation
- [ ] On first render, exactly 2 tiles are present on the board; all other cells are empty
- [ ] Clicking "New Game" resets the board to exactly 2 tiles and resets the score to 0
- [ ] Each spawned tile has value 2 or 4; no other values appear at spawn time

### Movement — basic
- [ ] Pressing ArrowLeft slides and merges all tiles leftward
- [ ] Pressing ArrowRight slides and merges all tiles rightward
- [ ] Pressing ArrowUp slides and merges all tiles upward
- [ ] Pressing ArrowDown slides and merges all tiles downward
- [ ] A move that does not change the board does not spawn a new tile

### Movement — merge correctness
- [ ] `[2, 0, 0, 2]` sliding left produces `[4, 0, 0, 0]`
- [ ] `[2, 2, 2, 2]` sliding left produces `[4, 4, 0, 0]` (each tile merges at most once)
- [ ] `[2, 2, 4, 0]` sliding left produces `[4, 4, 0, 0]` (merged 4 does not merge with existing 4)
- [ ] After any valid move, exactly one new tile (value 2 or 4) appears in a previously empty cell

### Score
- [ ] Score starts at 0
- [ ] Merging two tiles of value N increases the score by 2N
- [ ] Multiple merges in one move each add to the score
- [ ] "New Game" resets the score to 0

### Win
- [ ] When a tile reaches 2048, a win message is displayed
- [ ] No further arrow-key input is accepted after a win
- [ ] "New Game" button is visible after a win and resets the game

### Loss
- [ ] When the board is full and no adjacent tiles share a value, a loss message is displayed
- [ ] No further arrow-key input is accepted after a loss
- [ ] "New Game" button is visible after a loss and resets the game
- [ ] A full board with at least one adjacent equal-value pair does NOT trigger a loss

### Accessibility
- [ ] The game board region has an `aria-label`
- [ ] Each cell has an `aria-label` describing its current value (or "empty")
- [ ] The score display has an `aria-label`
- [ ] The status/message area has `role="status"` and `aria-live="polite"`
- [ ] "New Game" button has an accessible label
